Website structure

A multi-page project site for local stakeholder review.

Each page focuses on one part of the feasibility proposal, so stakeholders can review background, problem framing, selected design, prototype evidence, implementation, cost and recommendations without moving through one long document.

01

Country first

Information must support respect for Traditional Owners, cultural places and local protocols.

02

Practical access

Visitors and partners need reliable guidance about routes, seasons, facilities and safety.

03

Feasible delivery

The solution should be affordable to build, simple to update and resilient for remote operations.
